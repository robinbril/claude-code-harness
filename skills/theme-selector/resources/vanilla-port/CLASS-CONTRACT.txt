## Techniek (hard)

## HARD CLASS-CONTRACT. JS en CSS MOETEN deze EXACTE namen gebruiken
Dialoog-wrapper: #theme-modal.modal (overlay) bevat #theme-popup.tss-modal.modal-content (paneel).
Header: header.theme-popup-header bevat h2#theme-popup-title plus button.theme-close.
Tab-nav: nav#theme-tabs.theme-tabs (capsule) bevat button.theme-tab[data-tab="theme-tab-browse|theme-tab-customize|theme-tab-display"]. Actieve knop krijgt class is-active. Een schuivende pill span.theme-tab-indicator binnen #theme-tabs die via JS (left en width uit de actieve knop) meebeweegt.
Panelen: div.theme-tab-panel met id theme-tab-browse of theme-tab-customize of theme-tab-display. Verborgen paneel: attribuut hidden plus class is-hidden. Zichtbaar paneel: class is-active. CSS: .theme-tab-panel{display:none} en .theme-tab-panel.is-active{display:block}.
Themas-tab: div#themeGrid.theme-grid bevat per colourway button.cw-card[data-cw=id] met daarin div.cw-swatches (4x span.cw-sw) plus div.cw-label (span.cw-name plus span.cw-dot). Actieve kaart krijgt is-active.
Kleuren-tab: per kanaal div.cw-chan-row met label.cw-chan-label plus input[type=color].cw-chan[data-chan="bg|fg|panel|border|accent"]. Plus button.cw-reset met tekst Kleuren herstellen. GEEN preview die var-namen toont.
Weergave-tab: rijen div.display-row met label.display-label plus een control. Controls: select#theme-font-select, select#theme-density-select, iOS-switch label.switch met input#theme-frosted-toggle, input#theme-frost-range type range, input#theme-intensity-range type range, en materiaal-segment div#theme-material-seg met 3x button.material-opt[data-material="flat|frosted|liquid"] (labels Standaard, Matglas, Liquid Glass), actief krijgt is-active.
